# 星芒机器人功能说明

星芒是一个基于 OneBot 事件上报的 QQ 群聊机器人。它主要在指定 QQ 群中通过 `@星芒` 触发，支持 AI 问答、语音回复、科幻内容推荐、长期记忆、视觉内容、科幻故事接龙、协会信息服务和管理员维护。

本文档只描述当前“星芒”主机器人的功能，不包含独立的定时 @ 提醒机器人。

## 触发方式

- 在目标 QQ 群中 `@星芒` 后发送内容，星芒会自动回复。
- 指令需要以 `/` 开头，例如：`@星芒 /帮助`。
- 如果直接 `@星芒` 说话但不带 `/`，会默认作为 AI 提问处理。
- 如果只是单独 `@星芒`，会返回基础问候、最近活动和 `/帮助`。

## AI 问答

| 指令 | 功能 |
| --- | --- |
| `/提问 问题内容` | 调用 DeepSeek 生成回答 |
| `@星芒 问题内容` | 不带 `/` 时默认作为提问 |

AI 问答会结合星芒人设、用户长期记忆和同群最近几轮上下文，让连续追问和个性化回答更自然。

AI 回复当前只显示：

```text
🤖【星芒回答】
回答正文
```

已移除末尾的 `来自 DeepSeek · 星芒整理完成` 标记。

## 语音回复

星芒已接入火山 Seed-Audio 语音生成接口：

```text
POST https://openspeech.bytedance.com/api/v3/tts/create
model: seed-audio-1.0
```

当前语音策略：

- 默认先快速发送文字回复。
- 只有 `2.5%` 概率触发语音回复。
- 命中语音概率后，后台异步生成语音，生成完成后再补发 QQ 语音。
- 未命中语音概率时，只发送文字。
- 语音失败时不会影响文字回复。

当前语音配置重点：

```bash
VOICE_REPLY_ENABLED=1
VOICE_REPLY_ASYNC=1
VOICE_REPLY_PROBABILITY=0.025
TTS_PROVIDER=volcengine_seed_audio
VOLCENGINE_AUDIO_MODEL=seed-audio-1.0
VOLCENGINE_AUDIO_REFERENCE_LIMIT=3
```

音色参考文件来自：

```text
Tone_reference/normalized/
```

火山接口最多支持 3 个参考音频，因此当前使用 3 个参考音频，而不是 4 个。

当前音色方向偏可爱：年轻清亮、软乎、带明显笑意、中文少女感赛博机器人声线。

## 科幻故事接龙

星芒可以主持群内科幻故事接龙，支持报名、随机排序、轮流接龙、AI 点评打分和最终排名。

| 指令 | 功能 |
| --- | --- |
| `/科幻接龙` | 查看接龙菜单 |
| `/科幻接龙 规则` | 查看游戏规则 |
| `/科幻接龙 发起` | 发起一局接龙，发起人自动加入 |
| `/科幻接龙 加入` | 加入当前接龙 |
| `/科幻接龙 开始` | 发起人开始接龙并随机排序 |
| `/科幻接龙 顺序` | 查看当前接龙顺序 |
| `/科幻接龙 你的故事` | 轮到自己时提交故事内容 |
| `/科幻接龙 结束` | 发起人结束本局并公布排名 |

规则补充：

- 至少需要 2 位玩家才能开始。
- 只有发起人可以开始和结束本局。
- 星芒会对每段故事进行点评并打分，常规分数为 0-100，特别优秀时可能出现隐藏高分。
- 一局接龙 2 小时无人操作时会自动结算或取消。
- 管理员可以强制终止接龙。

## 长期记忆

星芒会记录通过 `@星芒` 触发的文本互动，用于形成用户画像和对话上下文。

会记录的内容包括：

- 群名片、昵称和用户自我介绍。
- 用户表达过的喜欢或不喜欢。
- 常用指令、常聊话题、活跃时间等行为统计。
- 用户语气习惯，例如句长、emoji 使用、玩笑频率和提问习惯。
- 同一群内最近几轮对话上下文。

| 指令 | 功能 | 权限 |
| --- | --- | --- |
| `/我的画像` `/我的记忆` `/记忆卡` | 查看星芒记住了什么 | 所有人 |
| `/忘记我` `/清除记忆` `/删除记忆` | 清空自己的全部记忆 | 所有人 |
| `/记忆概况` | 查看星芒记住了多少人和话题概况 | 管理员 |

隐私边界：

- 星芒只记录群内 `@星芒` 触发的消息。
- 不采集普通群聊内容。
- 不记录图片、文件等非文本内容。
- 用户可以随时查看或删除自己的记忆。
- 记忆指令不占每日配额，也不受 1 秒冷却限制。

## 自动推送

星芒支持以下自动任务：

- 北京时间 `0:00`、`6:00`、`12:00`、`18:00` 发送整点报时。
- 每天北京时间 `8:00` 自动发送今日星芒。
- 每天北京时间 `14:00` 自动发送今日星图。
- 每天北京时间 `20:00` 自动发送动漫推荐。
- 每 5 分钟检查一次科幻故事接龙是否超时，超过 2 小时无人操作会自动处理。

其中 `0:00` 和 `6:00` 的文案已改为普通提醒，不再使用“晚安提醒”和“早安提醒”。

## 低频主动插话

星芒现在会在目标群内缓存最近几条普通群聊消息，并低频、低概率主动插一句。

当前策略：

- 只在本机缓存最近消息，不把未 @ 星芒的普通群聊内容发送给 DeepSeek。
- 默认每 `15` 分钟检查一次。
- 每次检查每群约 `18%` 概率尝试主动回复。
- 每个群主动回复后默认冷却 `2` 小时。
- 默认凌晨 `1:00` 到 `7:00` 不主动插话。
- 同一批消息会记录摘要，避免重复回复。

相关配置：

```bash
PROACTIVE_REPLY_ENABLED=1
PROACTIVE_CHECK_SECONDS=900
PROACTIVE_REPLY_PROBABILITY=0.18
PROACTIVE_REPLY_COOLDOWN_SECONDS=7200
PROACTIVE_CONTEXT_MESSAGES=5
PROACTIVE_MIN_MESSAGES=3
```

## 表情素材池

星芒会定期刷新一批文本表情、颜文字和 emoji 组合，并覆盖旧批次，回复时随机低频混用，让语气更活一点。

当前策略：

- 默认每天刷新一次。
- 素材保存到 `runtime_cache/expression_pack.json`。
- 网络源不可用时使用内置 fallback 表情池。
- 当前实现使用文本表情/颜文字/emoji，不直接抓取第三方图片表情包。

相关配置：

```bash
EXPRESSION_REFRESH_SECONDS=86400
EXPRESSION_APPEND_PROBABILITY=0.32
```

## 使用限制

- 连续指令冷却时间为 1 秒。
- 每天最多回复 100 条普通指令。
- 配额在北京时间零点刷新。
- 管理员指令和记忆隐私指令不受普通配额限制。
- AI 问答需要配置 DeepSeek API Key；未配置时 AI 功能不可用。
- 语音回复需要火山 Seed-Audio API Key；未配置或生成失败时自动回退文字。
